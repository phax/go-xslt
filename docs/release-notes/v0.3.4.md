go-xslt 0.3.4 is faster again: copying a document, XPath and sorting are now quicker than with libxslt, grouping is on par, and template rules and validation are at most 1.3 times slower. Results are unchanged; every W3C conformance number is the same as in 0.3.3.

## Faster

| Workload (37 MB input) | go-xslt 0.3.4 | ratio to libxslt / libxml2 |
|---|---|---|
| copy the document | 0.80 s | 0.90× |
| recursive apply-templates | 2.00 s | 1.11× |
| sort by two keys | 1.09 s | 0.05× |
| Muenchian grouping | 0.91 s | 0.96× |
| XPath predicates and functions | 0.65 s | 0.71× |
| XSD 1.0 validation | 0.73 s | 1.34× |

- Documents without a `DOCTYPE` skip all DTD processing.
- Calling a template rule allocates less: no variable scope until a variable is bound, no candidate list for a single matching rule.
- Path expressions keep their starting node directly, and `@*|node()` has a fast path.
- Serialization writes tags without building intermediate strings.

Details and how to reproduce the numbers: [performance](https://tim-riep.github.io/go-xslt/performance).
