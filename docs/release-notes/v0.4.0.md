go-xslt 0.4.0 adds JSON formatting to the desktop tester. Every W3C conformance number is the same as in 0.3.9.

## Desktop tester

- **JSON output is pretty-printed** — the output pane's Format toggle, which already re-indented XML and HTML, now also formats the output of a stylesheet with `<xsl:output method="json"/>` (two-space indentation; output that is not valid JSON is shown as it is). JSON output is highlighted as JSON, and `.json` files in a project open with JSON highlighting.

## Build

- The release builds and CI install the Go version named by `go.mod`'s `toolchain` line, so the build tooling (the Wails CLI, govulncheck) is compiled with the same Go as the application. This removes a "file requires newer Go version" warning from the release builds; the binaries themselves were already built with that version.
